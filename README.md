# Cinematic TEA

A cinematic, scroll-driven interactive experience for **TEA**.

## Features

- **Scroll-Driven Hero Film**: Canvas scrub animation featuring 225 frames driven by scroll position.
- **Smooth Animations**: Powered by GSAP, ScrollTrigger, and Lenis smooth scrolling.
- **Responsive Design**: Fluid typography, responsive layouts, and performance optimizations for mobile.
- **Product Collection**: Interactive cards with micro-interactions.
- **Node/Express Backend**: Simple and robust static server with automatic asset validation.

## Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)

### Installation

```bash
# Clone the repository
git clone https://github.com/usman786-eng/Cinematic-tea.git
cd Cinematic-tea

# Install dependencies
npm install
```

### Running Locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
